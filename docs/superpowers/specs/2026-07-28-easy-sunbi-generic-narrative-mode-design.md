# 쉽선비 범용 역사 야담 서사 모드 설계

## 목적

`ship-sunbi-yadam`을 1890년대 파리·모파상에 종속된 시각 프리셋에서 분리하여, 여러 시대와 국가의 역사 소재에 재사용할 수 있는 범용 서사 모드로 만든다. 쉽선비는 한국어 말투와 이야기 전개 방식만 정의하고, 화면의 시대·지역·인물은 해당 사건의 역사 컨텍스트가 결정한다.

## 확인된 현재 상태

- `electron/services/style-presets.mjs`의 `ship-sunbi-yadam`은 쉽선비 서사 규칙보다 `Paris 1889`, 프랑스 복식, 모파상 외형을 강제하는 시각 정보가 중심이다.
- `electron/services/longform-planner.mjs`는 `genreMode === "yadam"`이고 기본 스타일이 전달되면 `ship-sunbi-yadam`을 자동 적용한다.
- 같은 플래너가 모든 야담 장면에 프랑스·파리·모파상 접두사를 추가한다. 따라서 고대 로마 같은 비프랑스 소재도 파리 장면으로 오염된다.
- 기존 구현에는 계획서가 설명한 쉽선비 말투와 Hook–Context–Climax–Outro 서사 구조를 대본 생성 단계에 적용하는 독립 구성요소가 없다.
- `getStylePreset()`은 프리셋을 찾지 못하면 기본 프리셋을 반환하므로 `getStylePreset("ship-sunbi-yadam") || getStylePreset("historical-paris-yadam")` 형태의 두 번째 폴백은 실행되지 않는다.
- 전용 회귀 테스트가 없으며 기존 `scripts/check-longform-production-contract.mjs`도 `scripts/youtube-draft-duration.mjs`의 `isLongform` 미정의 오류로 실패한다.

## 설계 원칙

1. 서사, 역사 사실, 시각 표현을 서로 독립된 책임으로 분리한다.
2. 사건의 지역과 시대를 알 수 없을 때 특정 국가나 문화를 추측하지 않는다.
3. 사용자가 명시적으로 선택한 시각 프리셋은 자동 장르 매핑보다 우선한다.
4. 기존 `ship-sunbi-yadam` ID는 저장된 작업과 UI 호환성을 위해 유지한다.
5. 파리 전용 시각 정보는 `historical-paris-yadam`에만 남긴다.
6. 외부 LLM 호출 없이도 핵심 조합 규칙을 결정적으로 테스트할 수 있어야 한다.

## 구성요소

### 1. 서사 모드

새로운 서사 모드 모듈은 `genreMode`에 대응하는 대본 작성 규칙을 반환한다. `yadam` 모드는 다음만 책임진다.

- 친근하지만 지나치게 희화화하지 않는 한국어 구어체
- 첫 부분의 구체적인 질문 또는 역설적 사실을 이용한 Hook
- 사건을 이해하는 데 필요한 Context
- 원인과 결과가 맞부딪히는 Climax
- 사실과 해석을 구분하는 Outro
- 낯선 제도나 단위는 짧은 현대적 비유로 설명
- 검증되지 않은 대사, 동기, 수치의 창작 금지
- 매 문단마다 같은 감탄사나 고정 문구를 반복하지 않기

이 규칙은 대본 생성 프롬프트에 주입하며 시각 시대, 민족, 복식을 포함하지 않는다.

### 2. 역사 컨텍스트

역사 컨텍스트는 다음 구조를 사용한다.

```js
{
  period: "",
  startYear: null,
  endYear: null,
  region: "",
  country: "",
  city: "",
  people: [
    {
      name: "",
      role: "",
      appearance: "",
    },
  ],
  wardrobe: [],
  architecture: [],
  materialCulture: [],
  exclusions: [],
  confidence: "explicit" | "researched" | "unknown",
  sources: [],
}
```

입력 우선순위는 다음과 같다.

1. 작업 요청에 명시적으로 저장된 구조화 컨텍스트
2. 검증된 리서치 브리프의 구조화 필드
3. 대본에 명시된 시대·지역 정보
4. 정보 부족 상태인 `confidence: "unknown"`

`unknown`일 때는 특정 국가, 민족, 실존 인물 외형을 생성 프롬프트에 추가하지 않는다. 추론 결과를 사실처럼 저장하지 않는다.

### 3. 시각 스타일

시각 스타일 프리셋은 실사, 삽화, 스틱맨 같은 표현 방식과 카메라·조명·색상만 정의한다.

- `ship-sunbi-yadam`: 범용 역사 다큐드라마 시각 스타일로 재정의하며 파리, 프랑스, 모파상 정보를 제거한다.
- `historical-paris-yadam`: 1880–1890년대 파리 전용 시각 프리셋으로 유지한다.
- 사용자가 `historical-paris-yadam`을 선택한 경우에만 파리 전용 제약을 적용한다.
- `preferredOutputModes`는 실제 출력 모드 결정 정책과 충돌하지 않도록 검증하되, 스타일 선택만으로 출력 모드를 강제로 변경하지 않는다.

### 4. 프롬프트 조합

장면 프롬프트는 다음 순서로 조합한다.

1. 화면 비율과 출력 모드
2. 장면의 서사적 역할
3. 화면으로 전달할 장면 의미
4. 구조화된 역사 컨텍스트
5. 선택한 시각 스타일
6. 캐릭터 연속성
7. 화면 내 글자·로고·시대착오 금지 규칙

서사 모드의 한국어 문구는 이미지 속 문자로 표시할 텍스트가 아니라 장면 의미로만 전달한다. 역사 컨텍스트와 시각 프리셋이 충돌하면 명시적 역사 컨텍스트가 우선하고, 충돌은 검증 결과에 기록한다.

## 데이터 흐름

```text
사용자 입력/리서치
  → 대본 생성: 서사 모드 규칙 적용
  → 역사 컨텍스트 정규화
  → 장면 분할
  → 프롬프트 조합: 장면 의미 + 역사 컨텍스트 + 시각 스타일
  → 안전 처리
  → Flow/이미지 생성기
```

직접 입력 대본은 내용을 다시 쓰지 않는다. 이 경우 서사 모드는 장면 역할과 시각 프롬프트 구성에만 사용하고, 원문 대본 변환은 별도 명시적 기능으로 남긴다.

## 호환성과 마이그레이션

- 저장된 작업의 `stylePresetId: "ship-sunbi-yadam"`은 계속 유효하다.
- 기존 ID가 더 이상 파리 전용 결과를 만들지 않는다는 동작 변경을 릴리스 노트에 명시한다.
- 파리 결과가 필요한 기존 작업은 `historical-paris-yadam`으로 명시적으로 전환할 수 있다.
- `genreMode: "yadam"`만으로 특정 시각 프리셋을 강제하지 않는다. 스타일 값이 없을 때에만 범용 기본 스타일을 선택한다.
- 사용자 지정 프리셋 객체가 있으면 ID 기반 자동 선택보다 우선한다.

## 오류 처리

- 알 수 없는 서사 모드는 기본 다큐멘터리 모드로 안전하게 폴백하고 진단 가능한 모드 ID를 남긴다.
- 역사 컨텍스트 필드가 잘못된 타입이면 빈 값으로 정규화하고 경고를 반환한다.
- 존재하지 않는 프리셋 ID는 조회 API에서 명시적으로 `null`을 반환하는 경로를 제공하여 폴백 정책을 호출자가 결정하게 한다.
- 컨텍스트와 프리셋의 지역·시대가 충돌하면 조용히 병합하지 않고 검증 경고를 생성한다.
- 프롬프트 안전 처리 후 필수 역사 컨텍스트가 사라지지 않았는지 계약 테스트로 확인한다.

## 검증 전략

### 단위 테스트

- 쉽선비 서사 규칙에 4단계 구조, 쉬운 비유, 사실/해석 분리 규칙이 포함된다.
- 서사 규칙에는 `Paris`, `France`, `Maupassant`, `조선`, 특정 복식이 포함되지 않는다.
- 역사 컨텍스트 정규화가 명시 값, 누락 값, 잘못된 타입을 안정적으로 처리한다.
- 프리셋 정확 조회와 미존재 조회를 구분한다.
- 프롬프트 조합 결과에서 화면 텍스트 금지와 컨텍스트 우선순위가 유지된다.

### 교차 소재 회귀 테스트

- 고대 로마 화재: 로마 컨텍스트가 포함되고 파리·모파상·프랑스 복식은 포함되지 않는다.
- 조선 시대 사건: 조선 컨텍스트가 포함되고 서양 복식·파리 요소는 포함되지 않는다.
- 1889년 파리 사건 + 파리 전용 프리셋: 파리와 프랑스 복식 제약이 유지된다.
- 시대·지역 미상 사건: 특정 국가·민족·실존 인물을 임의 삽입하지 않는다.
- 사용자가 선택한 비야담 스타일: `genreMode: "yadam"`이어도 선택한 스타일을 덮어쓰지 않는다.

### 통합 테스트

- 작업 요청 정규화 → 대본 또는 직접 대본 → 롱폼 장면 계획 → 저장된 미디어 계획까지 `genreMode`, `historicalContext`, `stylePresetId`가 보존된다.
- 이미지 전용, 하이브리드 출력에서 같은 역사 컨텍스트가 사용된다.
- 기존 롱폼 계약 테스트의 `isLongform` 오류를 먼저 수정한 후 관련 테스트 전체를 실행한다.

## 범위에서 제외

- LLM이 출처 없이 시대·지역을 자동 확정하는 기능
- 모든 국가와 시대를 위한 개별 프리셋 대량 추가
- 직접 입력 대본의 자동 문체 재작성
- CapCut 편집 규칙, TTS 음색, 자막 디자인의 전면 개편
- 기존 사용자 지정 프리셋 데이터의 파괴적 마이그레이션

## 완료 조건

- 비프랑스 야담 소재에서 파리·모파상 요소가 자동 삽입되지 않는다.
- 쉽선비 서사 규칙이 대본 생성 경로에 실제로 연결된다.
- 서사 모드, 역사 컨텍스트, 시각 스타일이 독립 모듈과 명시적 인터페이스로 분리된다.
- 기존 `ship-sunbi-yadam` ID가 호환성을 유지한다.
- 교차 소재 회귀 테스트와 관련 롱폼 계약 테스트가 통과한다.
- 기존 계획서와 완료 보고서의 과장된 구현 설명을 실제 구현 범위에 맞게 정정할 수 있다.
